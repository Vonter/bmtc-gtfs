# GTFS diffs

Run `python3 diff/diff.py` from the repository root to compare the working feed with
`gtfs/bmtc.zip` in `HEAD` (the last commit). This writes a compact
[Markdown report](diff.md) and a [GTFS Diff v2 JSON document](diff.json).
The script requires Python 3.11+ and no third-party packages.

Use `--base-ref <commit>` for an older baseline, or
`--base-feed old.zip --feed new.zip` for two local archives. Output paths can be
set with `--markdown` and `--json`; `--max-row-changes 0..50` controls the combined
row-example cap per file without changing the full counts. Inputs are snapshotted
and hashed before comparison. ZIP metadata and CSV row/column order are ignored.

The JSON targets MobilityData's published `2.0.0-rc1` schema, pinned under
`schemas/`. Numeric trip IDs are regenerated by the feed builder, so the
report includes route-level trip counts and identifies trip-ID reuse separately.

## Files

- [diff.py](diff.py): comparison script.
- [diff.md](diff.md) and [diff.json](diff.json): generated reports.
- [schemas/](schemas/): pinned MobilityData schema and provenance.
