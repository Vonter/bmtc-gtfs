# bmtc-gtfs

Unofficial GTFS dataset for BMTC bus services operated in Bengaluru, covering routes, stops, timetables, fares and more. Sourced from the official [Namma BMTC](https://nammabmtcapp.karnataka.gov.in/) app.

## Motivation

- [Why BMTC?](https://datameet.org/2016/08/05/bmtc-intelligent-transportation-system-its-open-transport-data/)
- [Why GTFS?](https://gtfs.org/#why-use-gtfs)

## Caveat

The source for the data and analysis in this repository is the information provided on the official Namma BMTC app. However, the Namma BMTC app has inaccurate data, and is known to have incorrect timetables and stop timings. Nonetheless, the data is representative of BMTC services and can be used to understand trends in the BMTC network.

Due to the design of the Namma BMTC app, only routes with functional live tracking are included in the GTFS. Missing routes may be due to unavailability of live tracking, and not necessarily due to the route not existing or being non-operational.

## Scripts

- [scrape.py](scripts/scrape.py): Fetch routes/stops/shapes/trips/translations from Namma BMTC 2.0, and platform/fare data from Namma BMTC
- [gtfs.py](scripts/gtfs.py): Parse raw data and save as GTFS
- [valiate.py](scripts/validate.py): Pass the GTFS through multiple GTFS validation tools
- [analysis.py](scripts/analysis.py): Export route, stop and aggregated-stop summaries as GeoJSON and CSV

## Raw JSON

Raw JSON data scraped from Namma BMTC 2.0 and Namma BMTC can be found below:

- [routes.7z](https://raw.githubusercontent.com/Vonter/bmtc-gtfs/main/raw/routes.7z): Namma BMTC 2.0's route catalog (one entry per route+direction, each with its ordered stop sequence, an encoded shape polyline, and Kannada stop-name translations)
- `raw/stop_schedules/`: Every scheduled trip's real per-stop arrival time, crawled per (stop, day) pair (gitignored -- regenerated by `scrape.py`, not distributed)
- [fares.7z](https://raw.githubusercontent.com/Vonter/bmtc-gtfs/main/raw/fares.7z): Fare matrix keyed by fare-stage code pairs (Namma BMTC; not currently wired into the GTFS build, see Known limitations below)
- [platforms/](raw/platforms): Platform locations and route-platform assignments for major bus stations (Namma BMTC; not currently wired into the GTFS build, see Known limitations below)

## Known limitations

Since migrating the static GTFS build to Namma BMTC 2.0:

- **Platforms and fares are not currently populated.** Namma BMTC 2.0 has no public equivalent yet for BMTC's platform/bay assignments or fare-stage data. `scripts/scrape.py`'s `get_platforms()`/`get_fares()`/`get_premium_fares()` and `scripts/gtfs.py`'s `add_platforms()`/`add_fares()` are kept in the code, unused, for when that data becomes available again.
- **`stop_desc` is no longer populated.** It previously came from BMTC's geofence-name data, which has no Namma BMTC 2.0 equivalent.
